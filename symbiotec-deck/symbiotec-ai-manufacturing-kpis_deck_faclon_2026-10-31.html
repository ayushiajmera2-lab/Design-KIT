08

From AI to agentic AI

AI / ML models

Score, predict, alert.

A person interprets the output.

One model, one question.

Insight arrives as a dashboard.

Agentic AI

Senses, reasons, plans, acts.

Ranks causes and prescribes actions.

Specialist agents work together.

Every step logged and governed.

09

A team of agents on every batch

Data agent

Pulls DCS, historian, LIMS. Flags bad sensors.

Monitoring agent

Compares live run to the golden envelope.

Prediction agent

Forecasts titer, by-products, harvest time.

Coordinated by a supervisor agent that decides: alert, recommend or escalate.

Diagnosis agent

Ranks likely root causes.

Prescription agent

Proposes bounded actions, tested on the twin.

Compliance agent

Audit trail, SOP checks, deviation drafts.

10

The golden batch loop

1  Build

Align best past batches. Set a multivariate envelope for each phase.

2  Watch

Compare every live variable to the envelope every few minutes.

3  Prescribe

Predict the shortfall, rank causes, recommend bounded fixes.

Tracked:

temperature

pH

dissolved oxygen

off-gas

agitation

aeration

foam

feed

offline HPLC
