01 · THE CHALLENGE

A design system that only Figma could read

Tokens, type, spacing, and imagery all lived inside a Figma file. Every time an AI tool needed to know what the brand actually looked like, it meant screenshotting a frame, copy-pasting a hex code, or manually exporting an image — repeated on every single update.

Manual screenshots and copy-pasted hex codes on every update
→
Tools query live tokens directly, no manual step
Images exported by hand and re-uploaded per task
→
Every tagged Figma frame syncs automatically
No single, current source of truth for AI-facing docs
→
One MCP server, one contract, always current
02 · THE SOLUTION

One server, three kinds of truth

Rather than teaching every AI tool how to open Figma, we built an MCP server that speaks for the design system directly — tokens, images, and a generated summary, always reflecting the current file.

1
Tokens
Color, typography, spacing, radius, and border/elevation values — queried as structured JSON, no screenshots involved.
2
Images
Every frame tagged "AI export" in Figma, exported and served as a real reference image on request.
3
Context doc
An auto-written markdown summary of the whole system — regenerated every time tokens or images change.

04 · THE PIPELINE

From a Figma save to a merged PR, in under a minute

The moment a version is saved in Figma, the whole system moves — no one has to remember to export anything.

1
Save triggers the webhook
A Figma version save fires a FILE_VERSION_UPDATE event — real time, no polling delay.
→
2
Server verifies & dispatches
The Railway-hosted server checks a shared passcode, then dispatches a GitHub Action.
→
3
Action exports & regenerates
Every "AI export" frame is exported; design-system.md is rebuilt from current tokens + images.
→
4
A PR opens automatically
Changes land as a reviewable pull request — merge to publish, nothing hand-copied.

06 · DESIGNED FOR FAILURE

Built to catch failure before it ships

"The failures worth designing for aren't the ones that crash. They're the ones that quietly look like success."

1
Collision-safe naming
Multiple Figma frames can share a name without data loss — every export gets a guaranteed-unique file, so nothing is ever silently overwritten.
2
Schema-validated automation
The GitHub Actions workflow is checked at the structural level, so a single formatting slip can't take the pipeline down unnoticed.
3
Named-output guarantees
Every exported asset is verified to have a real, descriptive filename before it's written — nothing ships nameless or untraceable.
07 · RELIABILITY

A live pulse on the system

A /health endpoint checks the server, tokens, images, and context doc independently — so a failure reports what actually broke, not just that something did. An external monitor pings it continuously and alerts by email the moment it can't.
